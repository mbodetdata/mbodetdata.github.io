# Politique de Sécurité - BMData

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité :

1. **NE PAS** la publier publiquement
2. Contactez : security@bmdata.fr
3. Décrivez la vulnérabilité en détail
4. Donnez-nous 30 jours pour corriger

Merci de votre responsabilité.

## Conformité

Ce site respecte :
- RGPD (données personnelles)
- Normes web modernes (sécurité)
- Accessibilité (WCAG 2.1)
