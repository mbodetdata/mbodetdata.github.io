## STRUCTURE DU REPO

Ce site est construit avec **Jekyll** et hébergé via GitHub Pages.

- `_data/` : données JSON/YAML (services, projets, etc.)
- `_includes/` : composants Liquid réutilisables
- `_layouts/` : templates Liquid
- `_posts/` : articles du blog
- `assets/` : CSS, JS, images
- `pages/` : pages statiques
- `portfolio/` : cas clients
- `scripts/` : outils internes (audit SEO, maillage) — non publiés
